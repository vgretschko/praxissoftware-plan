# Umsetzungsplan Praxissoftware Arbeitsmedizin

Übersicht über den Umsetzungsplan einer Praxissoftware für die arbeitsmedizinische Vorsorge: Kapitel, Fahrplan, Risiken und die offenen Entscheidungen, mit der Möglichkeit, zu kommentieren und zu entscheiden.

Online: https://vgretschko.github.io/praxissoftware-plan/

Die Seite ist eine einzelne HTML-Datei ohne externe Abhängigkeiten. Eingaben werden nur lokal im Browser zwischengespeichert und am Ende als Textdatei heruntergeladen. Die Seite wird aus dem nicht öffentlichen Projekt-Repository erzeugt; Änderungen bitte dort vornehmen, nicht hier.
